# 修复用量解析器

## 目标

- 修复 Swift 编译器无法在合理时间内检查距离计算表达式的问题。
- 恢复中文用量标签识别。
- 正确将“剩余”百分比转换为已使用百分比。
- 忽略 SwiftPM 本地配置目录。

## 执行计划

- [x] 拆分解析器中的复杂表达式，确保项目能够编译。
- [x] 添加中文标签并补充对应测试。
- [x] 将剩余百分比转换接入解析结果并补充边界测试。
- [x] 在 `.gitignore` 中添加 `/.swiftpm`。
- [x] 运行可用的解析器测试、类型检查及 diff 检查。

## 风险与取舍

- 保持现有 `UsageSnapshot` 的“已使用百分比”语义，不修改数据结构。
- 只扩展现有文本解析逻辑，不引入新依赖或抽象层。
- 当前执行环境为 Linux，缺少 macOS 的 `AppKit`，完整 `swift test` 与 `swift build` 只能在 macOS 上最终确认。

## 结果复盘

- 已拆分闭包中的类型推断表达式，解析器可独立通过 Swift 类型检查。
- 已支持中英文标签，并将“剩余”百分比统一转换为已使用百分比。
- 已通过 5 组中英文及边界场景的独立运行检查，`git diff --check` 通过。
- 完整包测试受 Linux 环境缺少 `AppKit` 限制，需在 macOS 上补充执行。
